## Objetivo

El operador ya no inventa claves de atributo en texto libre. La categoría define un conjunto pequeño y validado de campos.

## Qué se entregó

- Definiciones en el catálogo (Administrador): tipo cerrado texto / número / lista, etiqueta, clave, obligatorio, opciones.
- Registro, checklist de componente presente y edición ordinaria generan esos campos.
- El mock rechaza claves desconocidas y valida required / número / opciones. Datos históricos fuera del esquema actual se conservan al editar.
- Seed: Motor (cilindrada), Alternador (voltaje), Batería, Goma (CAT-002), Rin (CAT-003). Marca sigue siendo campo compartido, no atributo.
