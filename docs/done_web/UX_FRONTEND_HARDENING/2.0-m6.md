## Objetivo

Dejar claro por qué no se puede confirmar, llevar al primer campo incompleto, y sustituir confirmaciones lentas (quitar línea / descartar borrador) por deshacer de 3 segundos. En tablet/móvil las líneas se leen como tarjetas.

## Qué se entregó

- **6.1** Junto a `Confirmar venta` deshabilitado: el único bloqueo o `Faltan N requisitos`. La lista completa sigue en Totales.
- **6.2** `Ver requisitos` enfoca/desplaza el primer problema: cliente → precio pendiente → moneda → fiscal → otros. Ids estables `pos-customer`, `pos-currency`, `pos-fiscal`, más `pos-lines` / `pos-line-price-*` / `pos-blockers`.
- **6.3** Quitar línea y Descartar borrador (con líneas) ya no piden modal. Toast de 3 s con **Deshacer**. Borrador vacío se descarta al momento, como antes. Undo de descarte crea un borrador nuevo y restaura líneas/meta.
- **6.4** Desktop (`lg` / 1024 px): tabla. Debajo: tarjetas con cantidad, precio (`PriceCell`), ITBIS, total y Quitar.
