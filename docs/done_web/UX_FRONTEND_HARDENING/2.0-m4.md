## Objetivo

Una persona nueva debe poder registrar un artículo sin pelearse con scroll anidado, botones fuera de vista o un código interno que parece un campo editable.

## Qué cambió

- Un solo scroll: se quitó el wrapper `max-h-[75vh] overflow-y-auto`. El cuerpo de `Modal` es el único contenedor que desplaza.
- Acciones en `footer` (ya existía en `Modal`): `Cancelar` a la izquierda; `Registrar` / `Continuar` / `Registrar ensamblaje` a la derecha. En el paso 2 se conserva `Atrás` junto a la acción primaria.
- Código interno individual: texto de sistema, no un input deshabilitado. Sin categoría: «Se generará automáticamente al registrar.» Con categoría: prefijo al guardar. El SKU de `Producto por cantidad` sigue siendo un campo real.
- CTA post-alta: **Ver pieza** (individual / ensamblaje) y **Ver producto** (cantidad).
- Secciones visuales dentro del paso 1 (`fieldset`/`legend`, no pasos extra): Identificación, Inventario, Características, Evidencia. Marca, modelo, serial y notas siguen en `OptionalDetails`.
- Modal `size="lg"` para que las secciones no queden apretadas.
- Cierre seguro: un registro con cambios exige confirmar el descarte desde `Escape`, backdrop, X o **Cancelar**. Durante el guardado, el modal no puede cerrarse.
