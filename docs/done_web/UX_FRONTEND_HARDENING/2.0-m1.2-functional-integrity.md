## Objetivo

Ninguna acción visible (ni cola de trabajo) debe contradecir `ROLES_AND_PERMISSIONS.md`, `FEATURES` y `USE_CASE_FLOWS.md`.

## Qué se alineó

- **OT / desmonte (WO-003):** el vendedor no ve KPIs de cola, ni el listado de órdenes en el detalle de pieza, ni entra a `/work-orders`. El chip de trabajo físico en el estado de inventario se mantiene (concepto operativo INV-003).
- **Facturación:** cancelar, corregir moneda y rentabilidad se ocultan también con `can()`, no solo con flags del mock.
- **Catálogo pendiente:** el vendedor ve el estado del ensamblaje pero el texto aclara que no puede validar (CAT-001).
- **Inventario:** alta y correcciones protegidas usan `inventory.register` / `inventory.admin`.
- **Dashboard:** eventos de ganancia bruta / FX demo no se proyectan al vendedor.
